ACESSIBILIZA - SITE EM HTML, CSS E JAVASCRIPT

Abra index.html no navegador.

Estrutura:
- index.html: página inicial
- pages/: páginas internas
- css/global.css: Design System e componentes
- css/home.css: página inicial
- css/pages.css: páginas internas
- js/app.js: tema, contraste, favoritos e LocalStorage
- js/data.js: dados demonstrativos
- js/*.js: lógica específica das páginas

Não requer instalação, Node, React ou bibliotecas.

link do site: https://acessibiliza1.netlify.app/pages/login.html
